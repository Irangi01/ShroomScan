# Contact Section Background Images

This folder will contain the background image for the contact information card.

## 📁 Required Image

Place your background image in this location with this filename:
- **`contact-bg.jpg`** - Background image for contact information card (on contact.html)

## 📸 Image Specifications

- **Format**: JPG (JPEG) recommended, or PNG
- **Recommended Size**: 1200x600px or larger
- **File Size**: Keep under 1MB for fast loading
- **Aspect Ratio**: Wide format (landscape) works best
- **Content**: 
  - Agricultural/farming related imagery
  - Nature/plants/mushroom farming
  - Office/professional setting
  - Technology/IoT themed
  - Subtle background (not too busy)

## 🎨 Design Tips

For best appearance with the overlay:
1. **Use a subtle image** - The overlay is 95% white, so background should complement text
2. **High contrast** - Ensure text (brown #8a6a48) remains readable
3. **Professional quality** - Use high-resolution images
4. **Consistent branding** - Match your site's brown/tan color scheme
5. **Not too busy** - Avoid patterns that interfere with text readability

## 📸 Recommended Image Sources

Free resources:
- **Unsplash** (https://unsplash.com/) - Search "farm", "agriculture", "IoT", "greenhouse"
- **Pexels** (https://www.pexels.com/) - Free stock photos
- **Pixabay** (https://pixabay.com/) - Free high-quality images
- **Freepik** (https://www.freepik.com/) - Agricultural/farming themed

## 📝 How to Add Background Image

### Step 1: Find/Create Image
- Use any image editor to create or modify an image
- Recommended dimensions: 1200x600px or 1500x750px
- Save as JPG format

### Step 2: Place Image
1. Navigate to: `d:\Y4S2\ShroomScan\assets\images\`
2. Place your image as: **`contact-bg.jpg`**

### Step 3: Verify
1. Go to **Contact Us** page on your website
2. The contact information card should now display with the background image
3. Check that text remains readable (95% white overlay ensures visibility)

## 🎯 CSS Styling Applied

The background image will automatically have:
- **95% white overlay** - For text readability (rgba(255, 255, 255, 0.95))
- **Cover sizing** - Image covers entire card area
- **Fixed attachment** - Background stays fixed while scrolling
- **Centered positioning** - Image centered in the card
- **Rounded corners** - Matches card border-radius

You just need to place the image - the styling is automatic!
